# Databases

The tables in a database and the columns in each table are collectively known as the schema.

## Relational database

A database is called a relational database when it can model relationships between tables.

- Primary key in a relational database is a unique identifier that uniquely identifies each row in the table.

## SQLite

SQLite is a lightweight C library for relational database management using SQL.
